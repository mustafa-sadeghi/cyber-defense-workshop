# CYBER//AWARE — کارگاه تعاملی امنیت سایبری

یک GitHub Page تک‌صفحه‌ای و RTL برای ارائه کارگاه امنیت سایبری به زبان فارسی روان. رابط کاربری همان تم قبلی را حفظ می‌کند، اما محتوای کارگاه به **۱۲۹ صفحه/اسلاید** گسترش داده شده است.

## ساختار محتوایی

شروع کارگاه دیگر آزمون یا سؤال ناگهانی نیست. ارائه با روایت «یک روز عادی و ردپاهای دیجیتال» شروع می‌شود و بعد قدم‌به‌قدم وارد این موضوع‌ها می‌شود:

- مبانی امنیت سایبری و مفهوم سطح حمله
- مهندسی اجتماعی، فیشینگ، ویشینگ، BEC و MFA Fatigue
- پرونده‌های واقعی Twitter، Reddit، Uber، Target، Caesars و MGM
- OSINT در زندگی روزمره، مکان‌یابی تصویر، جست‌وجوی معکوس و راستی‌آزمایی
- معرفی کامل John McAfee و پرونده متادیتای عکس ۲۰۱۲
- معرفی کامل Strava، Heatmap و ماجرای OPSEC سال ۲۰۱۸
- معرفی Bellingcat و پرونده MH17 / ردیابی کاروان Buk با منابع واقعی
- OPSEC در خانه، محل کار، سفر و محیط‌های حساس
- Metadata / EXIF در عکس، Word و PDF
- Data Breach، Credential Stuffing و Password Reuse
- نمونه‌های ایرانی: اسنپ‌فود، تپسی، دیوار و پرونده ادعای هک دیجی‌کالا
- نمونه‌های خارجی: 23andMe، Equifax، Colonial Pipeline و SolarWinds
- QR / Quishing، Wi-Fi عمومی، Session Cookie و SIM Swap
- Deepfake، جعل صدا و سناریوهای مالی
- پاسخ به رخداد و چک‌لیست دفاعی پایان کارگاه

## حالت ارائه

صفحه به‌صورت پیش‌فرض در Presentation Mode باز می‌شود.

- `Space` یا `PageDown`: صفحه بعد
- `PageUp`: صفحه قبل
- `←`: صفحه بعد
- `→`: صفحه قبل
- `↑ / ↓`: اگر اسلاید طولانی باشد ابتدا داخل همان اسلاید اسکرول می‌کند؛ در انتهای محتوا به صفحه قبل/بعد می‌رود
- `P`: جابه‌جایی بین حالت ارائه و مطالعه
- `F`: تمام‌صفحه
- منوی بالا: دسترسی مستقیم به تمام بخش‌ها

## اجرای محلی

می‌توان فایل `index.html` را مستقیم باز کرد، اما برای Service Worker بهتر است یک وب‌سرور ساده اجرا شود:

```bash
python -m http.server 8080
```

بعد آدرس زیر را باز کنید:

```text
http://localhost:8080
```

## انتشار روی GitHub Pages

فایل‌های اصلی پروژه را در ریشه مخزن قرار دهید:

- `index.html`
- `styles.css`
- `app.js`
- `sw.js`

سپس از بخش **Settings → Pages** شاخه اصلی را برای انتشار انتخاب کنید.

## تصاویر و منابع

تصاویر پرونده‌های واقعی از آدرس اصلی رسانه‌ها و منابع تحقیقاتی بارگذاری می‌شوند و زیر هر تصویر توضیح داده شده که تصویر رخداد، تصویر آرشیوی یا ادعای مهاجم است. اگر یک منبع خارجی در شبکه کاربر قابل دسترس نباشد، صفحه به‌جای شکستن چیدمان، یک fallback توضیحی نشان می‌دهد.

برای نسخه کاملاً آفلاین یا استفاده در شبکه بسته، لازم است تصاویر دارای مجوز مناسب جداگانه در پوشه `assets/` ذخیره و مسیر `src` آن‌ها محلی شود.

## نکته آموزشی

متن‌ها عمداً توضیحی نوشته شده‌اند: قبل از هر پرونده ابتدا معرفی می‌شود فرد، شرکت یا سرویس چیست؛ سپس رخداد، اهمیت آن و درس دفاعی توضیح داده می‌شود. سؤال‌های شخصی بعد از توضیح مفهوم آمده‌اند تا مخاطب رفتار خودش را مرور کند، نه اینکه کارگاه با آزمون شروع شود.
